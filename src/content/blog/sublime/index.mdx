### Alpen - the light color scheme.   

<BlogImage 
  src={image1} 
  alt="sublime" 
  zoom={250} 
  position="top-left" 
/>

Install using Package Control   

- Enter `Package Control: Install Package`   
- Search for `Alpen Color Scheme`   
- Activating the Alpen Color Scheme   
- Preferences > Color Scheme > select > `Alpen`   

> [Alpen](https://github.com/yojeero/alpen_sublime) download from the GitHub.
